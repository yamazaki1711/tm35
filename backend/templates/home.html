Метрика про СРОКИ, не про людей — не путать с разделом «Укомплектованность ресурсом» ниже (докладная координатора: это две разные вещи, сливать в одну цифру нельзя — портит переговорную позицию, ТЗ 4.5). Плановый срок восстановлен из календарной матрицы Excel (первый/последний день с планом > 0) — по проверке матрица ведёт себя как график работ, не ресурсная разнарядка. Учитываются только работы с высокой или средней точностью восстановления срока ({{ crit.works_with_baseline_count }} из {{ works_total }}) — низкая уверенность (только текст «Месяц выполнения работ», без календаря) в этот расчёт не включена, чтобы не смешивать источники разной точности.

Калькулятор «Дата ↔ Люди» под директивный срок

Правильная формула (ТЗ 9.4.2, докладная координатора): остаток трудоёмкости ÷ оставшиеся рабочие дни — не сумма заявленной численности по активным работам (та формула давала 272 при 12 фактических — бессмысленно завышенное число, потому что не учитывала ни прогресс, ни последовательность работ). Остаток считается ТОЛЬКО по работам с реальной трудоёмкостью из календарной матрицы — работы без таких данных явно исключены из расчёта, не додуманы. Это арифметика, не полная симуляция ТЗ 9 (сценарии с сохранением вариантов — вне периметра).
