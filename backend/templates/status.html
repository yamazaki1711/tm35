S-кривая: трудозатраты нарастающим итогом, человеко-дни

Синяя — план по календарю Excel, зелёная — факт (обе нарастающим итогом). Фиолетовая точка — освоенный объём (взвешенный % × общая трудоёмкость) на последний день с фактом. Жёлтый пунктир — куда приведёт текущий темп, если не изменится. Серая горизонталь — весь объём работ по трудоёмкости ({{ total_trudoemkost }} чел-дн., только по работам с календарными данными — {{ known_work_count }} из {{ known_work_count + excluded_work_count }} активных).

Численность по дням: план / факт

Отклонение от директивного срока по неделям

Ноль — директивный срок (штриховая линия). Просрочка — положительное число дней (та же величина, что и в плитке выше: прогноз минус срок), опережение — отрицательное. Ниже нуля (залито слабым красным) — просрочка. Точки — по состоянию на начало недели, не пересчитываются задним числом: могут отличаться от плитки «Отклонение…» наверху, которая считает на сейчас. Копится по одной точке в неделю с {{ today|dmy }}.
