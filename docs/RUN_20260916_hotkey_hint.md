# TM-35 — подсказка Ctrl+Enter: по числу форм сохранения, не по имени класса, 16.09.2026

Находка координатора: `backend/static/hotkeys.js` показывал подсказку
«Ctrl+Enter» у любой кнопки сохранения, кроме `.btn-secondary` — это
угадывание по имени класса, а не условие самого хоткея, и оно ломается
ровно там, где хоткей и так неоднозначен. `/id-rsk-link` рендерит по
одной POST-форме «Прикрепить» на каждую строку кандидатов (до ~100) —
каждая проходила фильтр по классу, подсказка появлялась под каждой
строкой, а хоткей при этом ничего не делает (после поиска фокус остаётся
в GET-форме фильтра, кандидатов на срабатывание не один — правило
хоткея явно исключает этот случай).

## Правка

`allSaveForms()` (существующая функция — она же и решает, по какой
форме бьёт хоткей при фокусе вне формы) — единственный источник истины.
Подсказка теперь показывается только когда `allSaveForms().length ===
1`: это ровно тот случай, когда Ctrl+Enter однозначно бьёт по цели
независимо от фокуса. На странице с несколькими формами сохранения
подсказка не показывается вообще ни у одной — хоткей там по-прежнему
срабатывает при фокусе внутри конкретной формы, просто не
разрекламирован без адреса. Кнопка-действие в строке таблицы (например
«Убрать») отдельного условия не потребовала: при нескольких строках
форм несколько, `allSaveForms().length !== 1` выполняется сам собой.

Проверка класса `.btn-secondary`/`data-hotkey-save` для решения
«показывать подсказку или нет» убрана целиком — она относилась к
ВИДИМОСТИ подсказки, не к тому, какая кнопка сработает (это по-прежнему
решает `findButton()`, не тронут).

Заодно — `?v=` у `hotkeys.js` в `base.html` поднят до `20260916b` (не
трогать этот файл без бампа версии — иначе браузеры отдают закэшированную
старую копию).

## Проверено — обход всех маршрутов, ДО/ПОСЛЕ

Список маршрутов взят из собственной таблицы роутинга приложения (та
же `discover_routes()`, что и в `tools/ui_audit.py`), плюс
`/id-rsk-link?row_id=968` отдельно (маршрут требует `row_id`, поэтому
не входит в общий список без параметров). На каждой странице —
`document.querySelectorAll('.hotkey-hint').length`, дважды: со старым
`hotkeys.js` (временно восстановлен из бэкапа `hotkeys.js.bak.20260916_162521`,
снят перед деплоем) и с исправленным.

**Сдвинулось (4 страницы)**:

| Страница | До | После |
|---|---|---|
| `/today` | 316 | 0 |
| `/id-rsk-link?row_id=968` | 101 | 0 |
| `/id-entry` | 2 | 0 |
| `/id-folders` | 1 | 0 |

`/today` — 158 строк «Ограничения к снятию», у каждой строки две кнопки
(«Сохранить», «Снято»), ни одна не `.btn-secondary` — 316 = 158×2
подсказок висело подряд, хоткей не бил ни по одной определённо (форм
слишком много).

`/id-folders` — не была названа координатором явно, найдена тем же
обходом, тот же класс дефекта: подсказка висела у кнопки «Добавить»
(единственной, что проходила старый фильтр по классу), а на странице
рядом ещё N форм «Убрать» построчно в разделе «Незакрытый / невыбираемый
объём работ» (кнопка `.btn-secondary`, поэтому раньше не подсвечивалась,
но как ФОРМА всё равно считалась `allSaveForms()`) — хоткей был
неоднозначен и раньше, подсказка врала так же, как на `/id-rsk-link`,
просто с одной подсказкой вместо двадцати. Теперь корректно 0.

**Не изменилось (11 страниц с ровно одной формой сохранения — работали
верно и раньше, подсказка на месте)**: `/baseline`, `/blockers`,
`/changes`, `/journal`, `/login`, `/norm-plan`, `/report`, `/rsk/import`,
`/settings`, `/settings/users`, `/subcontractors`.

**Осталось 0 без изменений** — все прочие обнаруженные маршруты (страницы
без единой формы сохранения, например `/dashboard`, `/status`, `/gantt`,
`/shift`, `/id-progress`, реестры без формы добавления на самой
странице) — подсказки не было и нет, как и ожидалось.

**Ни одна страница не показывает больше одной подсказки после правки** —
проверено программно по всему списку маршрутов, дефектов не найдено.

**Ни одна страница не приобрела подсказку, которой не было** — ни одного
перехода 0→1 в полном обходе (сверено программно, не только по списку
выше).

## Скриншоты (1366×768)

`/today`, раздел «Ограничения к снятию»: до — «Ctrl+Enter» под каждой
из двух кнопок в каждой из 158 строк; после — ни одной подсказки на
экране, кнопки на месте, хоткей просто не разрекламирован.

`/id-rsk-link?row_id=968`: до — «Ctrl+Enter» под «Открепить» и под
каждым «Прикрепить» в списке кандидатов; после — ни одной подсказки.

`/changes` (контроль, не сдвинулась): подсказка при кнопке «Добавить
ИЗМ» — как была, так и осталась, единственная форма сохранения на
странице.
