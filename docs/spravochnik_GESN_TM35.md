# Справочник норм ГЭСН-2022 для ТМ-35

Официальные, современные (2022, Минстрой России) сметные нормы — заменяет более раннюю версию на базе ЕНиР (1999–2000, см. историю замен ниже). Источник — открытое API ФГИС ЦС (`fgiscs.minstroyrf.ru`), PDF каждого сборника сохранены в `import/enir_work/gesn_pdf/` для проверки. Разбор — `import/enir_work/parse_gesn.py`, из текста `pdftotext -layout`, числа сверены вручную построчно на нескольких сборниках разного формата таблиц.

## Сводка охвата

- Всего кодов ГЭСН в 12 сборниках: **12688**
- С извлечённой нормой (чел-час, рабочие+машинисты): **12369** (97.5%)
- Не разобрано автоматически: **319** (2.5%)

**Метод трудозатрат.** Для каждого кода — сумма двух строк ресурсной таблицы: «Средний разряд работы X,Y» (рабочие) + «Затраты труда машинистов» (машинисты, если есть). Расход материалов и машино-часы механизмов в справочник не включены (не нужны для расчёта человеко-часов).

## История замен

1. **18.08 — join со сметой ТМ-35 через ЕНиР** (отклонено координатором: «максимально далеко от того, что просил», числа не извлекались вовсе).

## Известные пробелы (честно)

- **Пусконаладочные работы (ПНР)** — отдельная линейка ГЭСНп (81-05-NN-2022, напр. Сборник 1 «Электротехнические устройства», Сборник 7 «Теплоэнергетическое оборудование») существует у Минстроя, но в этот справочник ещё не включена — не начато, отдельная задача при необходимости.
- Сварочные операции не выделены отдельным сборником (в ГЭСН, в отличие от ЕНиР, они встроены внутрь профильных сборников — напр. сварка металлоконструкций внутри сборника 9, сварка стыков трубопроводов внутри сборника 24/ГЭСНм-12) — искать по названию внутри соответствующего сборника, не по отдельному разделу «сварка».
- 2,5% кодов (см. лист «Не разобрано автоматически») не дали числа — таблица не подошла под распознанный шаблон парсера, не выдумано.
- **Название кода иногда неполное**, если заголовок-подсказка группы в источнике занимает больше одной строки (парсер берёт только последнюю строку заголовка перед кодом) — само число и код при этом верны, для точной формулировки сверяться с PDF в `gesn_pdf/` по номеру таблицы (напр. «Таблица ГЭСН 24-01-001»).
