# Расхождение продакшена и git — 15.09.2026

Сгенерировано сравнением реального дерева контейнера `tm_backend`
(`docker exec tm_backend tar -czf - -C / app`, снимок сохранён —
`~/tm35_prod_snapshots/tm35_prod_app_20260914_220851.tar.gz` на
kat-core, копия локально) против `origin/main` (после `git fetch`).
Не на глаз — списки построены через `diff -rq`/`comm` по двум
распакованным деревьям.

Соответствие путей: `/app/*.py`, `/app/static/`, `/app/templates/`,
`/app/Dockerfile`, `/app/requirements.txt` в контейнере = `backend/` в
git; `/app/tools/` в контейнере = `tools/` в git (корень репозитория).
Из сравнения исключены (не часть кода, легитимно отсутствуют в git):
`docs_import/`, `docs_report/`, `uploads/`, `.env`, все `*.bak.*`/
`*_bak` и директории `backup_*` (история ручных правок в контейнере,
не исходники), `__pycache__/`.

## 4. Что сделано с этим списком

- Бэкап живого `/app` контейнера снят и проверен ДО каких-либо правок
  (см. выше).
- Пункт 2 (8 файлов) занесён в git отдельным коммитом, обозначенным
  как синхронизация состояния прежних сессий, не моя работа — затем
  поверх отдельным коммитом легла работа этой сессии (задача 1). Оба
  коммита — `git log --oneline -5` в момент записи.
- Пункт 3 (4 файла) не трогался: они и так есть в git, отсутствие в
  проде для скриптов такого рода не обязательно дефект.

## 5. Отдельно, не в периметре этой задачи — только отметить

`pdfplumber`/`openpyxl` есть в `requirements.txt` в git, но не
установлены (согласно списку) в образе, из которого поднят текущий
`tm_backend`. `rsk_import_preview` (main.py) принимает загрузку PDF
акта — если разбор PDF использует `pdfplumber` и это единственная
причина зависимости, при следующей пересборке образа ИЗ requirements.txt
контейнер либо получит эту библиотеку (если раньше её не было и она
не используется — безобидно), либо, если код давно использует
`pdfplumber`, а сам пакет в живом образе стоит "случайно" из более
раннего слоя — пересборка с --no-cache может её потерять. Не проверял
глубже (вне периметра задачи 1) — координатору на заметку.
