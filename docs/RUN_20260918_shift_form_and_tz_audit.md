### Найденная и исправленная собственная регрессия

`render()` безусловно вызывал `setFactDate()` при смене даты. Эта
функция объявлена внутри `if (factForm) { ... }`, который выполняется
только когда форма реально на странице (`can_write=true`, право
`smr:write`). Для доступа только на чтение (в том числе для анонимного
прогона `ui_audit.py`, у которого нет сессии с этим правом) весь
`#shift-body` падал с `TypeError: setFactDate is not a function` вместо
таблицы — не только форма переставала работать, ломался весь экран.

Найдено не координатором, а собственной проверкой того же деплоя:
первый прогон `ui_audit.py` после деплоя показал у `/shift` падение
`small_font` с 26 до 9 на разрешение — втрое больше, чем разумно
ожидать от удаления одной модалки. Прямая проверка через Playwright
(`page.query_selector('#shift-body').inner_html()`) показала пустую
таблицу с текстом ошибки вместо строк — то есть находка выглядела как
улучшение, а была потерей данных на экране. Исправлено охраной
`if (dateChanged && factForm) setFactDate(...)`, передеплоено отдельным
коммитом (`6216949`) через несколько минут после первого (`2724e7d`) —
подробности в разделе «Деплой» ниже.
