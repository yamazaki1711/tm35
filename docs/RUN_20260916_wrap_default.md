# TM-35 — «текст переносится, не обрезается» как умолчание таблиц + проверяемость, 16.09.2026

Координатор: правило уже давалось раньше, применено к двум шаблонам
(`rsk_registry.html`/`rsk_processing.html`), но не к классу. Третий
экран (`/id-rsk-link`) сдан с текстом замечания РСК, обрезанным у
правого края, и кнопкой «Прикрепить», уведённой за пределы экрана на
1366×768. Задача — исправить причину, не один экран.

## §1 — причина

`backend/static/style.css`: `td, th { white-space: nowrap; }` глобально,
перенос — opt-in через `.wrap`. Сломанное состояние было умолчанием:
новая таблица с прозой обрезана, пока кто-то не вспомнит класс.

**Инверсия**: `td, th` теперь `white-space: normal; overflow-wrap:
break-word` по умолчанию. `.nowrap` — явный маркер атомарного значения
(дата, шифр, деньги, статус-бейдж, кнопка-действие). `.wrap` оставлен
no-op псевдонимом (совпадает с новым умолчанием) — разметку с `.wrap`
по всем шаблонам не трогал, как и просило задание.

Заодно поднят `th { font-size: .72rem }` (11.52px) до `.875rem` (14px) —
это была открытая находка KNOWN_ISSUES.md §40, отложенная координатору
«решение задело бы вёрстку всех таблиц разом». Теперь, когда шрифт
< 14px — измеримый, проверяемый дефект (§4 этого же задания), оставлять
заголовки таблиц ниже пола было бы гарантированным красным по всему
сайту с первого прогона нового чек-листа — поднял вместе с остальным.

## §2 — сплошной проход по таблицам

35 шаблонов с `<table>` (полный список см. `git show --stat` этого
коммита). Для каждой колонки — атомарное значение (дата/шифр/диапазон
участка/₽,%/чел.-дней/статус-бейдж/кнопка) помечено `.nowrap`, в
заголовке и в ячейках. Прозные колонки (наименование, описание,
комментарий, ФИО) оставлены с умолчанием (перенос) — где уже стоял
`.wrap`, не трогал.

**Не тронуты `/gantt` и `/shift`** — уже задокументированные исключения
до этой задачи: плотная сетка целиком в собственном `overflow-x`
контейнере (тот же принцип, что у матрицы ИД `/id-progress`), локальный
`<table class="gantt">` строится в JS и держит `white-space:nowrap`
намеренно (комментарий в коде — единственное разрешённое исключение из
правила «никаких многоточий», строка не самостоятельная запись, а срез
синхронизированной календарной сетки). `/shift` использует
`table-layout:fixed` с тем же принципом (свой `.table-wrap` со
скроллом) — но его собственные ячейки уже используют общие `.wrap`/
`.nowrap` классы, не локальный `white-space`, поэтому его я тоже
прошёл (пропущенные колонки без класса — «Участок»/«Статус» — раньше
полагались на глобальный nowrap-умолчание, теперь помечены явно).

**Инцидент, найденный самим же новым чек-листом**: заголовок
«% готовности» на `/shift` помечен `.nowrap` по инерции (как и соседние
атомарные заголовки), но колонка там `table-layout:fixed` шириной
6.5rem (104px) — заголовку в 14px нужно ~130px, обрезался. Заголовок —
короткая фраза, не атомарное значение (в отличие от данных в колонке,
которые все — числовые input'ы), снят `.nowrap`. Пойман
`tools/ui_audit.py` при первом прогоне, не глазами — именно ради такого
случая и строился чек-лист.

## §3 — `/id-rsk-link`

Приведён к тому же паттерну, что `rsk_registry.html`/`rsk_processing.html`:
- контент-ячейка «Содержание» → `.rsk-content-cell` + `.rsk-sentence-clip`
  (превью — первые два предложения, тот же регекс, что в
  `rsk_processing.html`, включая исключение цифр перед точкой/номером
  пункта) + `#rsk-tooltip` по наведению — переиспользован код 1-в-1, не
  третья копия;
- поле поиска расширено (`min-width:24rem`) под свой плейсхолдер
  «например, 210 или свайные фундаменты» — раньше не помещался;
- колонка «Прикрепить»/«Открепить» — `.nowrap`, теперь помещается на
  экране без прокрутки на 1366×768 (проверено: `scrollWidth ≤
  innerWidth` на всех трёх разрешениях).

**Заголовок «Изоляция — Опв1- УТ1»**: проверено прямым запросом к БД —
`id_form_row.id=968, section_label='Опв1- УТ1'` (висящий дефис,
строчная «п» в «Опв»). Это ДАННЫЕ, не склейка шаблона (`{{ tab_label }}
— {{ label }}` — один разделитель между вкладкой и меткой, второй
дефис — внутри самого `section_label`). Правило проекта — не
нормализовать данные молча. Не трогал, отмечаю координатору отдельной
строкой (не заводил отдельный пункт KNOWN_ISSUES — единичный случай,
не системный паттерн, если найдутся другие — тогда отдельная задача).

## §4 — `tools/ui_audit.py` — от «написан, не задеплоен» до реального гейта

Файл существовал в git, отсутствовал в контейнере
(`docs/PROD_SYNC_2026-09-15.md` §3). Проверено: `playwright` с Chrome
уже установлен и рабочий в `tm_backend` (`channel="chrome"` и bundled
chromium оба живые) — устанавливать ничего не пришлось.

Доведён до требований задания:
- список маршрутов — `discover_routes()` читает `app.routes` (GET, без
  `{param}` в пути, не `/api|/static|/export`), не жёсткий список.
  Маршрут, которому всё равно нужен обязательный query-параметр (напр.
  `/id-rsk-link` — `row_id`), получает не-200 и печатается как
  пропущенный, не проваливает прогон — такие экраны проверяются
  отдельно, с реальным id (см. §3 выше, сделано вручную браузером);
  `/docs`, `/redoc`, `/openapi.json` (служебные маршруты FastAPI)
  исключены явно — `/docs` тянет внешний CDN-скрипт и виснет на
  networkidle без интернета из контейнера;
- Basic Auth сделан необязательным (снят со всего сайта 29.08.2026,
  `docs/AUTH_2026-08-29.md`) — переменные окружения поддержаны для
  обратной совместимости, не блокируют запуск при отсутствии;
- четыре измеримых дефекта теперь дают ненулевой код выхода (было —
  только печать): горизонтальная прокрутка страницы
  (`document.scrollWidth > clientWidth`), шрифт < 14px, элемент за
  правым краем viewport, обрезанная (`scrollWidth > clientWidth`)
  ячейка таблицы. Оба последних явно игнорируют содержимое ВНУТРИ
  контейнера со своим `overflow-x:auto/scroll` (обходят предков до
  `document.body`) — матрица ИД/`/gantt`/`/shift` не проваливают
  проверку своей законной внутренней прокруткой; ячейка с явным
  `text-overflow:ellipsis` (видимый клип, не молчаливый) тоже
  пропускается.

**Живой прогон, все обнаруженные маршруты, 3 разрешения**:
- `horizontal_scroll`: **0** находок ни на одной странице;
- `off_viewport`: **0** находок;
- `clipped_cell`: **0** находок (после исправления `/shift`, см. §2);
- `small_font`: **2604** находки — воспроизводимо на каждой странице,
  не относится к переносу текста (см. KNOWN_ISSUES.md §44 — отдельная,
  крупная, добеска до этой задачи, не чинил, координатору на решение);
- `container_width`/`short_row`: информационные, не проваливают код
  выхода (как и было изначально, не по теме этого ТЗ).

`check_consistency.py` — 68/68, без расхождений, после всех правок.
