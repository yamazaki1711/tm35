## Требует решения координатора (продолжение)

- Конвенция недель "1-7/8-14/15-21/22-конец месяца" не найдена в
  проекте как уже существующая — реализована с нуля по полной

- Значение ячейки матрицы = количество видов работ, переданных именно
  на статус "Первичная проверка РСК" в этом периоде (не весь цикл РСК
  целиком). Если нужно шире — например, считать вхождение в любой шаг
  цикла подписания (Первичная проверка/Устранение замечаний/Повторная
  проверка) — это одна строка фильтра в `compute_id_matrix()`, не
  структурная правка.
- Drill-down показывает раздел целиком (все виды работ), не только те,
  что попали именно в кликнутый период — альтернативное прочтение
  (period-specific breakdown) не реализовано, при необходимости легко
  добавить фильтр по датам внутрь того же запроса.
