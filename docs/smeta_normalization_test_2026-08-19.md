# Тест «можно ли нормировать виды работ ТМ-35» — 19.08.2026

По прямому вопросу координатора: сопоставил 512 позиций ведомости
работ по РД (смета — единственный источник с реальными физическими
объёмами м3/м2/шт, в отличие от 163 работ Excel ПТО, где объёмов нет)
со справочником норм — сначала СТО-ССР (основной), при отсутствии —
ГЭСН (вспомогательный).

## Итог

**56 из 512 позиций (10,9%) сопоставлены надёжно и посчитаны —
14 645 человеко-часов суммарно.** Из них 27 позиций (5,3%) — по
СТО-ССР, 29 (5,7%) — по ГЭСН. Основной охват — раздел «Устройство
трубопроводов» (промывка/испытание, укладка стальных труб по
диаметрам, установка отводов) — это ядро физического объёма ТМ-35 как
раз хорошо покрыто. Остальные ~89% позиций сметы — либо составные
формулировки (несколько операций в одной строке), либо не имеют
прямого аналога в 7 разделах СТО-ССР/16 сборниках ГЭСН, либо единица
измерения нормы не подошла (намеренно отклонено, не считано наугад).

## Как дошли до этого числа — два ложных промежуточных итога, оба пойманы вручную до показа координатору

1. **Первый прогон дал 1 206 248 человеко-часов** — оказалось, что 690
   тыс. из них (больше половины) — одна ошибочная пара: «Установка
   закладных деталей» (смета, единица «кг», объём 16 767 кг)
   сопоставилась с нормой СТО-ССР «за 1 шт. детали весом свыше 4 кг» —
   у нормы в источнике не сохранилась единица измерения, код принял
   объём в кг за количество деталей. **Исправлено: единица измерения
   стала обязательным условием сопоставления, а не бонусом к скору**
   (`normalize_smeta.py::best_match()`).
2. **После фикса — 176 позиций, но ручная проверка топ-15 по вкладу**
   выявила ту же самую ошибку как главный вклад — после полного
   исправления охват упал до 56 позиций и итог до 14 662.
3. При ручной проверке итогового списка из 56 найдена ещё одна плохая
   пара («Прокладка трубы» → «Прокладка волоконно-оптических кабелей»
   — общее слово «прокладка», разные предметы) — исключена вручную,
   финальное число **14 645**.

## Вывод для координатора

Нормировать виды работ ТМ-35 **можно, но частично и только там, где
объём известен** — у сметы (512 позиций) это получается для ~11%
позиций автоматически, у Excel ПТО (163 работы) не получается вообще
(нет физических объёмов, см. `docs/spravochnik_SSR_SpiderProject_TM35.md`
и историю в CLAUDE.md). Для остального понадобится либо ручной подбор
нормы человеком по каждой оставшейся позиции сметы (справочник для
этого уже есть и работает — экран `/norms`), либо более точный источник
объёмов по 163 работам ПТО, которого сейчас нет ни в одном файле проекта.
