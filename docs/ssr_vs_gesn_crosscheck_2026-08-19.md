# Сверка СТО-ССР vs ГЭСН — 19.08.2026

По прямому указанию координатора: раз Spider Project вероятно
подключён к ГЭСН через API, сверил числа трудоёмкости там, где
операции пересекаются. Метод — тот же принцип сопоставления по ключевым
словам/единице/полярности монтаж-демонтаж, что уже применялся в
проекте, плюс две новые находки-исправления по ходу (см. ниже).

## Итог одной строкой

**Автоматическое сопоставление находит пару хоть для 84 из 365 (23%)
операций СТО-ССР — для остальных 77% в ГЭСН нет очевидного аналога** (другая
грануляция/лексика). Из найденных 84 пар вручную проверено на
правдоподобие — **надёжных, действительно одна и та же операция,
осталось около 20**; остальные — совпадения по случайным словам
(«Монтаж ЗРА» → «Трелевка древесины», «Валка деревьев» → «Корчевка
пней» — разные операции, не расхождение норм, а ошибка сопоставления).
**Гипотеза «Spider Project практически повторяет ГЭСН» не
подтверждается и не опровергается однозначно** — среди надёжных пар
есть и почти точные совпадения (0.78–0.99), и устойчивые расхождения в
1.3–3.6 раза.

## Две находки по ходу сверки (важны сами по себе)

1. **Разный базис единиц.** ГЭСН публикует нормы на 100/1000 единиц
   («100 шт», «1000 м3»), СТО-ССР — всегда на 1 единицу. Без поправки
   первые результаты показывали «расхождение в 30–300 раз» там, где
   реального расхождения не было вовсе (пример: «Установка
   дорожных знаков» — 30x на деле оказалось не единичной ошибкой
   норматива, а тем, что не поделили на 100). Исправлено в
   `crosscheck_ssr_gesn.py::norm_unit_and_mult()`.
2. **Слова материала нельзя убирать в стоп-слова для этой сверки** (в
   отличие от прежних сопоставлений в проекте) — иначе «Сварка
   стальной трубы» сопоставляется со «Сваркой полиэтиленовых труб».
   Добавлена явная проверка конфликта материала
   (`material_conflict()`).

**Читается так:** сварка (и ПЭ, и сталь) у СТО-ССР устойчиво на
27–75% выше ГЭСН — правдоподобно, реальные полевые условия обычно
менее «оптимальны», чем усреднённая госнорма. Отделочные/поверхностные
операции (обеспыливание, обезжиривание, столбы) расходятся сильнее — в
2.6–3.6 раза, СТО-ССР выше. Опалубка/бетонирование/щебень/крепление
щитами — близко (0.4–1.9x, без явного системного сдвига в одну
сторону).

## Явно отсеянные ложные совпадения (для памяти — не искать в них смысл)

Валка деревьев ↔ корчевка пней; монтаж ЗРА (арматура трубопроводов) ↔
трелевка древесины / монтаж задвижки резервуара; демонтаж стальной
трубы ↔ трубопровод водоотлива в стволе шахты; бурошнек ↔
ударно-канатное бурение скважин (разная технология); установка
дорожных знаков — единицы несовместимы («шт» vs «т стоек»), сравнивать
нельзя в принципе без веса конкретного знака.
