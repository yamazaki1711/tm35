фильтры. **Разрыв:** нет. Закрыто ночным прогоном + доводкой status/

### 4.2. Контроль план/факта по срокам и ресурсам

**Сейчас:** план/факт **по ресурсам** (людям, по датам) — есть, дашборд
«Ресурсы». План/факт **по срокам** — **отсутствует полностью**: нет
сравнения «должно было закончиться тогда-то, реально идёт с таким-то
темпом», потому что нет baseline с датами (только помесячная привязка в
части строк Excel, не извлекалась). **Разрыв: критический**, закрывается
Циклом 1 (временный baseline из "Месяц выполнения работ") — частично, до
уровня месяца, не до дня.

### 4.3. Выявление критических работ и ограничений

**Сейчас:** ограничения (`blocker`) — только 23 день-уровневых записи
общего характера (погода/ГСМ), не привязанные к конкретной работе,
залитые ночью. Критических работ (тех, что реально угрожают сроку) —
**не выявляется вообще**, показывается плоский список без ранжирования.
**Разрыв: критический**, закрывается Циклом 1 (критерий критичности —
просрочка относительно baseline-месяца + статус).

### 4.4. Моделирование сроков завершения работ

**Сейчас: отсутствует полностью.** Нет ни прогнозной даты, ни расчёта
темпа. **Разрыв: критический**, закрывается Циклом 1 — ограниченно:
расчётный прогноз по фактическому темпу ресурса, НЕ полный интерактивный
модуль симуляции «Дата→люди»/«Люди→дата» (тот по решению координатора
остаётся во 2-й итерации, вне периметра). Разница явно обозначается на
дашборде.

### 4.5. Подготовка переговорной позиции между Заказчиком и Исполнителем

**Сейчас:** есть раздел «Обоснование Исполнителя», но он показывает
агрегаты без интерпретации («план X, факт Y») — не даёт готового
аргумента «нам нужно N человек, дано M, дефицит K, это стоит объекту N
дней». **Разрыв: значительный**, закрывается Циклом 1 (явная связка
дефицит → влияние на срок).

### 4.6. Формирование управленческих дашбордов

**Сейчас:** 11 разделов есть, но часть из них — витрины сырых записей без
аналитической надстройки (ранжирования, приоритизации, интерпретации).
**Разрыв: частичный**, закрывается по мере Циклов 1 и 3.
