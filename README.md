# ТМ-35 — мониторинг СМР и контур ИД

Подсистема мониторинга строительно-монтажных работ и исполнительной
документации по объекту «Тепломагистраль-35» (г. Хабаровск, заказчик
ООО «ИКС-Хабаровск»). Backend на FastAPI + Jinja2, PostgreSQL.

Живой стенд: https://tm.asd-kontur.ru (Basic Auth).

## Структура репозитория

- `backend/` — FastAPI-приложение (роуты, шаблоны, статика, Dockerfile)
- `migrations/` — SQL-миграции схемы БД `tm35`, по порядку номеров
- `deploy/` — nginx-конфиги поддомена и вспомогательные скрипты
- `tools/` — служебные скрипты (аудит, функциональные проверки)
- `docs/` — техническая документация: разбор данных, схема ИД-контура,
  журналы реинжиниринга, справочники ГЭСН/ССР
- `CLAUDE.md` — постоянный контекст проекта для Claude Code (архитектура,
  находки, история решений)
- md-файлы в корне и `280826/` — брифинги и отчёты по итогам сессий
  (снимки состояния на конкретную дату, не источник истины по коду)

## Деплой

Код на сервере (`kat-core`, контейнер `tm_backend`) обновляется **без
git** — файлы копируются в образ (`docker cp`), `main.py` требует
`docker restart tm_backend`, шаблоны `.html` подхватываются на лету.
Этот репозиторий — снимок кода, не источник деплоя.

## Что не включено

Служебные секреты (`.secrets/`), справочные материалы большого объёма
(ЕНиР, импортируемые Excel-графики, исходные ТЗ) и артефакты визуальной
приёмки (скриншоты) в репозиторий не включены — только код и
документация.
