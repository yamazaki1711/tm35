# Импорт контура РСК

**Актуальная схема/импорт** — `docs/RSK_ACT_PDF_IMPORT_2026-09-06.md`.
Первоисточник — только PDF-акт проверки (Excel ПТО подключается
отдельным этапом позже).

```
python3 parse_act_pdf.py           # PDF -> parsed_act.json, ничего не пишет в БД
TM35_DSN=... python3 load_act.py   # parsed_act.json -> Postgres (upsert по act_no/sys_no)
```

Источник — `../../Акт проверки № 4183-159 от 11.08.2026 (1).pdf`, путь
захардкожен в `parse_act_pdf.py` (`PDF_PATH`).

---

`parse_rsk.py`/`load_rsk.py`/`parsed.json` — **отменённая** версия от
того же дня (Excel-реестр как первоисточник, схема `022_rsk_contour.sql`).
См. пометку в начале `docs/RSK_KONTUR_IMPORT_2026-09-06.md`. Файлы
оставлены как есть (не удалены) — код разбора Excel-реестра и текст
дефектов источника может пригодиться, когда Excel-слой ПТО подключат
отдельным этапом; таблицы `022` в БД уже удалены миграцией
`023_rsk_pdf_only.sql`, так что `load_rsk.py` без новой миграции не
запустится.
