# Слияние с origin/main — статус на 08.09.2026, промежуточная точка

Координатор уходит с этой машины на другую посреди разбора. Этот файл — снимок
состояния для продолжения на новой машине или в новой сессии. Не источник
истины о проекте (для этого CLAUDE.md/KNOWN_ISSUES.md) — только карта, где
именно остановилась работа по слиянию.

## Контекст

`origin/main` (GitHub, `git@github.com-tm35:yamazaki1711/tm35.git`) отстал от
локальной работы с 03.09.2026 — 9 коммитов independently запушены через
веб-редактор GitHub где-то в другом месте 04.09.2026, локальная работа с тех
пор шла своим путём. Обнаружено 07.09.2026 при попытке `git push`. Координатор
велел не пушить силой, разбирать конфликт по файлам с показом и подтверждением
по каждому — этот разбор идёт с того момента.

**Ветка разбора:** `merge-origin-04-09`, создана от `main` в этой сессии,
`git merge origin/main --no-commit --no-ff`. `main` не трогать до полного
согласования — это правило координатора действует до сих пор.

## Важно: main не тронут

Все обычные правки этой сессии (откат самодеятельности РСК, фикс дефиса в
парсере акта, уборка пояснительных текстов, компактные легенды графиков) —
на `main`, закоммичены, актуальны. Слияние идёт ПАРАЛЛЕЛЬНО на отдельной
ветке и `main` не переписывает. Оба — `main` и `merge-origin-04-09` —
запушены на origin отдельными ветками (не `main` на GitHub — тот всё ещё
на `origin/main`, трогать его нельзя до завершения слияния), чтобы работа
была доступна с любой машины: `origin/main-wip-2026-09-08` (снимок main) и
`origin/merge-origin-04-09` (разбор конфликта).
